# 11 111 км на велосипеде / 31 день

Двуязычный статический сайт велосипедного ультрамарафона Виктора Доронина:
11 111 км с 1 по 31 декабря 2026 года. Русская версия находится в `/`,
английская — в `/en/`.

## Структура

- `src/` — единая RU/EN-модель содержания, стили, скрипт и исходные медиа;
- `src/project-plan.json` — канонический календарь 22 базовых дней и пяти
  специальных этапов `333 → 555 → 777 → 999 → 1111`;
- `src/content/diary/` — одна структурированная RU/EN-запись на файл; диапазон,
  карточки и полноформатные записи собираются автоматически;
- `site/` — готовая к публикации сборка;
- `reference/11111-life-original.html` — контрольная копия исходного
  [11111.life](https://11111.life/);
- `docs/` и `AGENTS.md` — продуктовые, типографические, локализационные и
  доступностные правила проекта.

Презентации и исходные фотографии не копируются в репозиторий целиком. В сайт
попадают только отобранные и оптимизированные изображения без переноса
презентационной вёрстки.

## Сборка и проверка

```sh
node scripts/validate-project-plan.mjs
node src/build.mjs site
node src/check.mjs site
```

Социальные превью воспроизводимо пересобираются из текущего постера командой
`pnpm social:build`.

Workflow `.github/workflows/pages.yml` публикует каталог `site/` при обновлении
ветки `main`.

Обычная публикация выполняет `pnpm gate`: проверяет план, статус и данные,
собирает сайт и проверяет статический контракт. Браузеры при публикации не
устанавливаются. Плановый запуск тем же путём обновляет прогноз пыли.

Для микро-правки один раз проверяем изменённое место локально и один раз —
после публикации на сайте. Полный набор доступности, браузеров, медиа, тем
и скриншотов вынесен в отдельный ручной workflow `Full site checks`; локальная
команда — `pnpm gate:full`. Он не блокирует workflow публикации.

## Архивный заезд 2024 года

`src/ride-film.mjs`, `src/assets/ride-film.js` и `76-ride-film.css` собирают
принятый эпизод между календарём и дневником. `src/assets/ride-film/sources.json`
фиксирует интервалы исходного фильма и четыре периода конечного монтажа.
Видео загружается после действия зрителя и воспроизводит свой родной звук.
Полная длительность с остановками — 38:36:20, в движении — 27:13:09;
источник — `src/ride-2024-laps.json`. GPX задаёт геометрию, а не точное время
каждого кадра. Контроль плеера: `node scripts/ride-film-check.mjs site`.

В CI воспроизведение проверяется в Chromium на Linux и WebKit на macOS,
где плеер использует медиастек Safari. Публикация требует успеха обеих
проверок; доступность, темы и геометрия WebKit также проверяются на Linux.
