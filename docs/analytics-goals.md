# Цели Яндекс Метрики

Единственный машиночитаемый реестр находится в
`src/analytics-goals.json`. Счётчик: `111159425`.

## Покрытие

| Группа | Цели |
|---|---|
| Навигация | `menu_open`, `chapter_navigation` |
| Конверсия | `project_explore`, `partner_interest` |
| Вовлечение | `diary_explore`, `diary_follow` |
| Предпочтения | `language_switch`, `theme_change` |
| Медиа | `hero_video_pause`, `hero_video_resume`, `diary_video_start`, `diary_video_complete` |
| Доказательства | `proof_open` |
| Контент | `diary_open`, `calendar_open`, `film_open` |
| Контакт | `contact_email`, `contact_telegram` |

## Privacy contract

В параметры попадают только заранее разрешённые категориальные значения:
идентификатор раздела, фаза календаря, язык, тема и
место переключателя.
Адреса, имена, контактные значения, полный URL, свободный текст и содержимое
полей не отправляются. `app.js` отбрасывает неизвестные цели, неизвестные ключи
параметров и значения вне безопасного формата.

`src/check.mjs` требует, чтобы реестр был полным: каждая цель должна иметь
реальный статический или программный триггер, а ни HTML, ни JavaScript не могут
отправить цель вне реестра.


## Служебные просмотры

Единое условие в `src/assets/app.js` исключает localhost, loopback,
браузерную автоматизацию (`navigator.webdriver`), явный адрес `?service=check`
и параметры стенда `phase`, `calendar`, `text`, `theme`, `film`,
`browser-regression`. В этих случаях счётчик не загружается, не
инициализируется и не получает цели. Переключение предпочтения на «включено»
не отменяет это условие. Сохранённый выбор посетителя остаётся его выбором.
Обычные ссылки с `release` и UTM-параметрами сохраняют аналитику.

`pnpm gate --check analytics` проверяет эту границу в настоящем браузере,
отдельно проверяет реальные цели и включение/отключение для обычного визита.
Сценарий обычного посетителя использует локальную копию на виртуальном
публичном домене, имитирует неавтоматизированный браузер и подменяет Метрику
записью вызовов; данные тестов не уходят в реальный счётчик.
