# Обновление статистики проекта

До подтверждённого старта `src/project-status.json` намеренно содержит
`verified: false` и только `null`: сайт показывает честное состояние ожидания,
а не подставные цифры.

## Получение данных

Обновление принимается только из датированного источника команды или публичной
записи проекта. Нужны одновременно: момент обновления с часовым поясом,
пройденная дистанция, текущая дисциплина на русском и английском, локализованное
название источника и публичный HTTPS-адрес источника.

## Запись

```sh
node scripts/update-project-status.mjs \
  --updated-at '<ISO-8601 с часовым поясом>' \
  --distance-km '<число от 0 до 11111>' \
  --discipline-ru '<подтверждённая дисциплина>' \
  --discipline-en '<утверждённый перевод>' \
  --source-label-ru '<название источника>' \
  --source-label-en '<source label>' \
  --source-url '<https://...>'
```

Необязательные `--note-ru` и `--note-en` добавляют только подтверждённое
пояснение. Перед записью ту же команду можно выполнить с `--dry-run`.

## Gate

1. `node scripts/validate-project-status.mjs`
2. `node src/build.mjs`
3. `node src/check.mjs`
4. browser/screenshot gate активного состояния

Схема `src/project-status.schema.json` и программный валидатор запрещают
неполные локали, неизвестные поля, дистанцию вне диапазона, источник без HTTPS
и скрытые цифры при `verified: false`. Для возврата к пустому состоянию есть
явная команда `node scripts/update-project-status.mjs --reset`.
