# Обновление статистики проекта

До подтверждённого старта `src/project-status.json` содержит историю версии 2
с пустым массивом `entries`. Сайт показывает ожидание; история дистанции и
пройденная часть линии не появляются. План не выдаётся за результат.

Каждая запись — подтверждённый снимок версии 1. Текущий статус вычисляется из
последней записи; прежние отметки сохраняются вместе с датой и источником.

## Получение данных

Обновление принимается только из датированного источника команды или публичной
записи проекта. Нужны одновременно: момент обновления с часовым поясом,
пройденная дистанция, текущая дисциплина на русском и английском, локализованное
название источника и публичный HTTPS-адрес источника.

## Запись

```sh
node scripts/update-project-status.mjs \
  --updated-at '<ISO-8601 с часовым поясом>' \
  --distance-km '<число от 0 до 11111>' \
  --discipline-ru '<подтверждённая дисциплина>' \
  --discipline-en '<утверждённый перевод>' \
  --source-label-ru '<название источника>' \
  --source-label-en '<source label>' \
  --source-url '<https://...>'
```

Команда добавляет запись в конец истории. Необязательные `--note-ru` и
`--note-en` добавляют только подтверждённое пояснение. Перед записью ту же
команду можно выполнить с `--dry-run`.

## Gate

1. `node scripts/validate-project-status.mjs`
2. `node src/build.mjs`
3. `node src/check.mjs`
4. browser/screenshot gate активного состояния

Схема `src/project-status.schema.json` и программный валидатор запрещают
неполные локали, неизвестные поля, дистанцию вне диапазона и источник без HTTPS.
Отметки должны идти строго по времени, не раньше старта и не из будущего;
накопленная дистанция не уменьшается. Исправление ошибочной отметки делается
явно в исходнике с сохранением истории Git. Команда
`node scripts/update-project-status.mjs --reset` очищает всю историю.

## Видимый след и возвращение

После первой отметки линия пяти вершин получает постоянный пройденный участок,
а под календарём появляются текущий итог и раскрываемый список источников.
Между отметками километры не прибавляются автоматически. Это подтверждённые
данные команды, а не GPS-трекер.

`journey.js` сохраняет в localStorage только идентификаторы увиденных материалов
(`11111-seen-updates-v1`). Первый визит создаёт исходную точку без уведомлений.
При последующем визите новые записи дневника и дистанции показываются полосой
«С прошлого посещения». Материал считается увиденным, когда статья или история
попали в область просмотра; простая загрузка страницы не снимает отметку.
При запрете хранилища основной сайт работает без этой необязательной полосы.
